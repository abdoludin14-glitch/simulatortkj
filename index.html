Kebutuhan Instalasi Fisik & Pengkabelan Jaringan LAN

1. Perangkat Keras Wajib: Router Gateway, Switch LAN, Kabel UTP (Cat5e/Cat6), Konektor RJ-45, Tang Crimping, dan LAN Cable Tester.

2. Urutan Kabel Straight-Through (EIA/TIA-568B):
Pin 1: Putih-Oranye • Pin 2: Oranye • Pin 3: Putih-Hijau • Pin 4: Biru • Pin 5: Putih-Biru • Pin 6: Hijau • Pin 7: Putih-Cokelat • Pin 8: Cokelat.

3. Pengujian LAN Tester: Pastikan lampu indikator 1 sampai 8 pada Master & Remote menyala berurutan tanpa ada pin yang putus atau tertukar.

Daftar Kebutuhan Instalasi & Konfigurasi LAN

1. Perangkat Keras (Hardware)
  • Router Gateway: MikroTik / Cisco / RouterBoard.
  • Switch LAN: Pembagi jalur kabel klien.
  • Access Point: Jika butuh WiFi nirkabel.
  • Perangkat Klien: PC/Laptop ber-NIC.
  • Kabel UTP & RJ-45: Cat5e/Cat6 standar T568B.
  • Alat Kerja: Tang Crimping & LAN Cable Tester.
2. Perangkat Lunak (Software)
  • Winbox / WebFig: Aplikasi konfigurasi Router MikroTik.
  • PuTTY / SSH: Akses terminal CLI router.
  • OS Klien: Windows / Linux dengan driver NIC aktif.
  • CMD / Terminal: Pengujian ping, ipconfig, tracert, nslookup.
3. Parameter Logika (Level 8)
  • Interface: ether1-ISP & ether2-LAN.
  • DHCP Client: Minta IP WAN dari ISP.
  • IP Address LAN: 192.168.10.1/24.
  • IP DNS: 8.8.8.8 & 1.1.1.1.
  • DHCP Server: Pool IP otomatis klien.
  • Firewall NAT: srcnat + masquerade.
